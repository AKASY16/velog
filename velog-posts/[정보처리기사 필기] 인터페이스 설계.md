<h3 id="1-요구사항-검증-방법">1. 요구사항 검증 방법</h3>
<h4 id="동료검토peer-review-명세서-작성자가-직접-명세서를-설명하고-동료들이-명세서에-대해-결함을-검토하는-식의-방법">동료검토(Peer Review): 명세서 작성자가 직접 명세서를 설명하고, 동료들이 명세서에 대해 결함을 검토하는 식의 방법.</h4>
<h4 id="워크스루walk-through-회의-전-명세서를-미리-검토하여-사전-검토하여-짧은-검토-회의를-통해-결함을-검토하는-식의-방법">워크스루(Walk Through): 회의 전, 명세서를 미리 검토하여 사전 검토하여 짧은 검토 회의를 통해 결함을 검토하는 식의 방법.</h4>
<h4 id="인스펙션inspection-명세서-작성자를-제외하고-다른-전문가들이-명세서를-확인하며-결함을-검토하는-식의-방법">인스펙션(Inspection): 명세서 작성자를 제외하고, 다른 전문가들이 명세서를 확인하며 결함을 검토하는 식의 방법.</h4>
<h4 id="인스펙션은-공식적인-검토-방법이고-동료검토와-워크스루는-비공식적인-검토-방법이다">인스펙션은 공식적인 검토 방법이고, 동료검토와 워크스루는 비공식적인 검토 방법이다.</h4>

<h4 id="송신-시스템-연계-프로그램으로부터-생성된-데이터를-전송-형식에-맞게-인터페이스-테이블이나-파일로-변환-후-송신하는-시스템-비유하자면-편의점-pos기가-발생한-판매-데이터를-본사-양식장부나-파일으로-예쁘게-포장해서-던져주는-것">송신 시스템: 연계 프로그램으로부터 생성된 데이터를 전송 형식에 맞게 인터페이스 테이블이나 파일로 변환 후 송신하는 시스템. 비유하자면, 편의점 POS기가 발생한 판매 데이터를 본사 양식(장부나 파일)으로 예쁘게 포장해서 던져주는 것.</h4>
<h4 id="수신-시스템-수신된-인터페이스-테이블이나-파일을-연계된-프로그램에서-처리할-수-있도록-변환한-후-연계프로그램에-반영하는-시스템을-말함-설령-송신-시스템이-완벽하게-처리해-넘겨주었더라도-수신-시스템은-송신-시스템들에서-넘어온-정보들을-교통정리하거나-보기-편하게-만드는-것을-말함">수신 시스템: 수신된 인터페이스 테이블이나 파일을 연계된 프로그램에서 처리할 수 있도록 변환한 후 연계프로그램에 반영하는 시스템을 말함. 설령 송신 시스템이 완벽하게 처리해 넘겨주었더라도 수신 시스템은 송신 시스템들에서 넘어온 정보들을 교통정리하거나, 보기 편하게 만드는 것을 말함.</h4>

<h3 id="1-미들웨어">1. 미들웨어</h3>
<h4 id="분산-컴퓨팅-환경에서-서로-다른-하드웨어-프로토콜-통신-환경-등에서-유연하게-연결될-수-있도록-돕는-소프트웨어-운영체제-응용-프로그램-서버-클라이언트-등의-환경에서-원활한-통신이-이루어질-수-있도록-돕는-역할도-있다-11-1n-n1-nm-등의-여러-형태로-연결-가능하다">분산 컴퓨팅 환경에서 서로 다른 하드웨어, 프로토콜, 통신 환경 등에서 유연하게 연결될 수 있도록 돕는 소프트웨어. 운영체제-응용 프로그램, 서버-클라이언트 등의 환경에서 원활한 통신이 이루어질 수 있도록 돕는 역할도 있다. 1:1, 1:N, N:1, N:M 등의 여러 형태로 연결 가능하다.</h4>
<h4 id="위치-투명성을-제공하며-내부-동작-로직을-확인하기-위해서는-별도의-소프트웨어가-필요하다">위치 투명성을 제공하며, 내부 동작 로직을 확인하기 위해서는 별도의 소프트웨어가 필요하다.</h4>
<h4 id="종류로는-db-rpc-mom-tp-moniter-orb-was-등이-있다">종류로는 DB, RPC, MOM, TP-Moniter, ORB, WAS 등이 있다.</h4>
