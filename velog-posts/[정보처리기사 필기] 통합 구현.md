<h3 id="1-단위-모듈unit-module의-개요">1. 단위 모듈(Unit Module)의 개요</h3>
<h4 id="소프트웨어-구현에-필요한-여러-동작-중-한-가지-동작을-수행하는-기능을-모듈로-구현한-것">소프트웨어 구현에 필요한 여러 동작 중 한 가지 동작을 수행하는 기능을 모듈로 구현한 것.</h4>
<h4 id="단위-모듈을-구현하는-방법-중-하나가-흔히-아는-클래스class다-단위-모듈의-본질은-단일-책임이고-클래스는-객체지향적-방식으로-그것을-표현한-것이다">단위 모듈을 구현하는 방법 중 하나가 흔히 아는 '클래스(Class)'다. 단위 모듈의 본질은 단일 책임이고, 클래스는 객체지향적 방식으로 그것을 표현한 것이다.</h4>
<h4 id="단위-기능-명세서-기능-및-코드-명세서나-설계-지침처럼-단위-기능을-설계-과정에서-명세화한-문서를-말한다">단위 기능 명세서: 기능 및 코드 명세서나 설계 지침처럼 단위 기능을 설계 과정에서 명세화한 문서를 말한다.</h4>
<h4 id="입·출력-기능-구현-단위-기능-명세서에서-정의한-데이터-형시에-따라-입·출력-기능을-위한-알고리즘-및-데이터">입·출력 기능 구현: 단위 기능 명세서에서 정의한 데이터 형시에 따라 입·출력 기능을 위한 알고리즘 및 데이터.</h4>
<h4 id="알고리즘-구현-입·출력-데이터를-바탕으로-단위-기능별-요구-사항들을-구현-가능한-언어를-이용해-모듈로-구현">알고리즘 구현: 입·출력 데이터를 바탕으로 단위 기능별 요구 사항들을 구현 가능한 언어를 이용해 모듈로 구현.</h4>
<br />

<h3 id="2-ipcinter-process-communication">2. IPC(Inter-Process Communication)</h3>
<h4 id="모듈-간-통신-방식을-구현하기-위해-사용되는-대표적-프로그래밍-인터페이스-집합">모듈 간 통신 방식을 구현하기 위해 사용되는 대표적 프로그래밍 인터페이스 집합.</h4>
<h4 id="복수의-프로세스를-구행하며-이뤄지는-프로세스간-통신까지-구현-가능함">복수의 프로세스를 구행하며 이뤄지는 프로세스간 통신까지 구현 가능함.</h4>
<h4 id="파이프-소켓-세마포어-등이-그-예시다">파이프, 소켓, 세마포어 등이 그 예시다.</h4>

<h3 id="1-통합-개발-환경ide-intergrated-development-environment">1. 통합 개발 환경(IDE; Intergrated Development Environment)</h3>
<h4 id="코딩-디버그-컴파일-배포-등-개발과-관련된-모든-작업을-하나의-프로그램에서-처리할-수-있도록하는-소프트웨어적인-개발-환경을-말한다">코딩, 디버그, 컴파일, 배포 등 개발과 관련된 모든 작업을 하나의 프로그램에서 처리할 수 있도록하는 소프트웨어적인 개발 환경을 말한다.</h4>

<br />

<h3 id="2-통합-개발-환경-도구의-기능">2. 통합 개발 환경 도구의 기능</h3>
<h4 id="코딩coding-프로그래밍-언어로-프로그램을-작성하는-기능">코딩(Coding): 프로그래밍 언어로 프로그램을 작성하는 기능</h4>
<h4 id="컴파일compile-개발자가-작성한-고급-언어로-된-프로그램을-컴퓨터가-이해-가능한-목적-프로그램으로-번역해-컴퓨터에서-실행-가능한-상태로-변환하는-기능">컴파일(Compile): 개발자가 작성한 고급 언어로 된 프로그램을 컴퓨터가 이해 가능한 목적 프로그램으로 번역해 컴퓨터에서 실행 가능한 상태로 변환하는 기능.</h4>
<h4 id="디버깅debugging-소프트웨어나-하드웨어의-오류나-잘못된-동작-즉-버그bug를-찾아-수정하는-기능">디버깅(Debugging): 소프트웨어나 하드웨어의 오류나 잘못된 동작, 즉 버그(Bug)를 찾아 수정하는 기능.</h4>
<h4 id="배포deployment-소프트웨어를-사용자에게-전달하는-기능">배포(Deployment): 소프트웨어를 사용자에게 전달하는 기능.</h4>
